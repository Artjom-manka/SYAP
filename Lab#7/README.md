# ЛР 7 — Веб-сайт «Инерционные танки»

**Вариант 14 · «Инерционные танки»**

Адаптивный многостраничный сайт на HTML, CSS и JavaScript. Объединяет:

- ядро игры на JS (ЛР 4) — физика инерционного танка, коллизии, `Game` / `Level`;
- Canvas-виджет (ЛР 5) — отрисовка лабиринта и танка, ввод с клавиатуры;
- панель шасси (ЛР 6) — CRUD в LocalStorage; карточки шасси выводятся в хотбар;
- динамический HUD — скорость, время, статус, позиция, угол.

## Структура проекта

```
LR7_tanks_site/
├── index.html                  # главная: шапка, HUD, холст, хотбар, подвал
├── pages/
│   └── inventory.html          # страница инвентаря (CRUD шасси из ЛР 6)
├── css/
│   └── style.css               # тема (CSS-переменные), Grid/Flexbox, медиазапросы
├── js/
│   ├── core.js                 # единая точка подключения ядра (ЛР 4)
│   ├── widget-integration.js   # Canvas-виджет: цикл, отрисовка, ввод
│   ├── hud.js                  # динамический индикатор состояния
│   ├── hotbar.js               # карточки шасси из LocalStorage
│   ├── storage.js              # ключи, load/save, escapeHtml, валидация
│   ├── crud.js                 # CRUD-логика для страницы инвентаря
│   └── site.js                 # бургер-меню и инициализация
├── docs/                       # скриншоты для README
└── README.md
```

Ядро лежит **в соседней папке** `internal_tanks_js/` и подключается через `js/core.js`:

```
Репозиторий/
├── internal_tanks_js/   # ядро (ЛР 4)
├── LR6_tanks_crud/      # CRUD (ЛР 6)
└── LR7_tanks_site/      # этот проект
```

Если ядро находится в другом месте, поменяйте пути в `js/core.js` — больше нигде они не указаны.

## Запуск

ES-модули требуют HTTP, по `file://` браузер блокирует импорты.

```bash
# из корня репозитория (рядом лежат internal_tanks_js и LR7_tanks_site)
python -m http.server 8000
```

Откройте <http://localhost:8000/LR7_tanks_site/>.

## Управление

| Клавиша       | Действие                          |
|---------------|-----------------------------------|
| `W` / `↑`     | ускорение вперёд                  |
| `S` / `↓`     | ускорение назад                   |
| `A` / `←`     | поворот влево                     |
| `D` / `→`     | поворот вправо                    |
| `R`           | рестарт игры                      |

На мобильных экранах под полем появляются сенсорные кнопки ◀ ▲ ▼ ▶.

## Как это работает

### Каркас (Grid + Flexbox)

- **CSS Grid** задаёт каркас главной (`grid-template-areas`): `header` на всю ширину, слева `hud`, в центре `main`, ниже `hotbar` и `footer`.
- **Flexbox** используется внутри блоков: шапка и навигация, панель HUD, хотбар, центрирование канваса.
- Все цвета и шрифт вынесены в CSS-переменные (`:root`), единый стиль на всех страницах.

### Интеграция виджета

`site.js` динамически импортирует `widget-integration.js`, тот импортирует ядро через `core.js`.
Виджет только рисует и читает клавиши, вся физика выполняется в `Game.step()`. Шаг фиксированный: 1/60 с с накопителем времени.
Если ядро не загрузилось, на холсте выводится сообщение об ошибке, а хотбар и навигация продолжают работать.

### Хотбар и LocalStorage

- Ключ `tank_presets` — тот же, что в панели CRUD (ЛР 6).
- `hotbar.js` читает массив и строит карточки (название + характеристики), все строки проходят через `escapeHtml`.
- Клик по карточке выделяет её рамкой, сохраняет id в `tank_selected` и вызывает `widget.setPreset()`: параметры `thrust`, `friction`, `maxSpeed` применяются к танку.
- Если страница инвентаря открыта в соседней вкладке, карточки обновляются через событие `storage` без перезагрузки.

### Динамический HUD

Значение берётся из движка: `level = |v| / maxSpeed` (0…1), где `|v| = hypot(vx, vy)`.
Каждый кадр обновляются `textContent` и `style.width` существующих элементов, DOM-узлы не пересоздаются.

| Уровень   | Подпись   | Цвет индикатора |
|-----------|-----------|-----------------|
| < 3 %     | СТОИТ     | зелёный         |
| < 33 %    | СПОКОЙНО  | зелёный         |
| < 66 %    | РАЗГОН    | жёлтый          |
| ≥ 66 %    | ДРИФТ!    | красный + свечение |

Также выводятся статус игры, время, позиция, угол и название выбранного шасси.

### Адаптивность (≤ 768 px)

- Сетка перестраивается в одну колонку: поле → HUD → хотбар.
- Верхняя навигация заменяется кнопкой-«бургером» ☰ с выпадающим меню (класс `open`).
- Скрыты второстепенные элементы: подзаголовок, подсказки, подвал, подробные строки HUD.
- Холст ограничен по высоте окна (`max-height: calc(100dvh - …)`), `body { overflow: hidden }`, поле всегда видно целиком.
- Добавлены сенсорные кнопки управления.

## Как проверить

1. Откройте «Инвентарь», добавьте шасси «Лёгкий» (0.1 / 0.97 / 4) и «Тяжёлый» (0.04 / 0.99 / 2).
2. Вернитесь на главную — карточки в хотбаре. Выберите одну: рамка становится зелёной, в HUD меняется «Шасси».
3. Езжайте на W/A/D: индикатор проходит стадии СТОИТ → СПОКОЙНО → РАЗГОН → ДРИФТ!. У «Лёгкого» разгон резче.
4. Откройте инвентарь во второй вкладке и добавьте запись — карточка появляется в хотбаре главной без перезагрузки.
5. DevTools → режим устройства (ширина ≤ 768 px): бургер открывается и закрывается, страница не прокручивается, видны HUD, хотбар и сенсорные кнопки.
6. Перезагрузите страницу — карточки и выбранное шасси сохранились.
