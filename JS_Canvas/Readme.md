# intertial_tanks_widget — Веб-виджет Inertial Tanks (ЛР 5)

Интерактивный веб-виджет игры «Inertial Tanks» на HTML5 Canvas. 
Является графической оболочкой для ядра, написанного в Лабораторной работе №4. 
Игровая логика (физика танка, коллизии, стены, состояния) полностью импортируется из соседней папки ядра.

Фиксированный шаг симуляции: FRAME_MS = 1000 / 60 (около 16.67 мс).

Накопитель (accumulator): гарантирует, что ядро шагает равномерно, независимо от частоты кадров монитора.

Защита от «прыжка»: deltaMs = Math.min(now - last, 100) — если вкладка была свёрнута, танк не телепортируется через всю карту.

Радиус видимости (туман): VISIBLE_RADIUS = 260 пикселей. Всё, что дальше, не отрисовывается, а поверх накладывается радиальный градиент.

Реализованные механики Canvas
```
Ввод без задержек: используется массив-флагов keys = {}. События keydown/keyup только меняют состояние (true/false), а цикл loop() опрашивает их каждый кадр. Это избавляет от «рывков» при удержании клавиши.

Ограниченная видимость: стены отрисовываются только если расстояние от танка до центра стены меньше VISIBLE_RADIUS.

Анимация эффектов: при движении танка над ним появляется желтый индикатор. Его прозрачность (alpha) плавно затухает в зависимости от скорости с использованием rgba(255, 200, 60, alpha).

HUD (интерфейс): обновляется через textContent DOM-элементов. Показывает статус партии, время, скорость (через Math.hypot), координаты и угол танка.
```
