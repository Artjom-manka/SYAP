# Telegram-бот аналитик для игры Inertial Tanks

Бот-помощник для игры, разработанной на Pygame. Бот не дублирует игру, а работает с её выгрузками: читает таблицу рекордов (`agent_logs.csv`) и лог событий (`game_flight.log`), строит таблицу лидеров, личную статистику и выдает достижения.

## Возможности бота

- **🏆 Топ игроков**: таблица лидеров по времени выживания в игре.
- **📊 Моя статистика**: количество сессий, суммарное время, количество тревог и лучшее время за сессию.
- **🏅 Мои ачивки**: 2 достижения, привязанные ко времени игры (Спринтер, Марафонец).
- **📤 Загрузка результатов**: можно отправить боту CSV-файл, он его проверит, очистит от ошибок и добавит в общую базу.
- **🔔 Подписка**: уведомления о появлении новых записей в базе.
- **Антифлуд**: бот редактирует существующее сообщение-экран вместо отправки новых.

## Требования

- Python 3.10 или выше.
- Установленная библиотека `aiogram` версии 3.x.

Структура проекта
```
Tanki_Bot/
├── bot.py              # Точка входа, обработчики команд и кнопок (aiogram 3)
├── config.py           # Настройки, чтение токена из .env, пути к файлам
├── session.py          # Stateless-сессии: хранение профилей в JSON
├── analytics.py        # Парсинг CSV/лога, верификация, расчет рекордов и ачивок
├── keyboards.py        # Инлайн-клавиатуры (меню и кнопки)
├── requirements.txt    # Зависимости проекта
├── .env                # Секретный токен (не загружать в GitHub!)
├── agent_logs.csv      # База результатов (создается автоматически)
├── game_flight.log     # Лог событий игры (создается автоматически)
└── sessions/           # Папка с JSON-сессиями пользователей (создается автоматически)
```
Как игра взаимодействует с ботом
Бот ищет файлы agent_logs.csv и game_flight.log в той же папке, где лежит bot.py.

Ваша игра сохраняет результаты в формате:
Сессия, Имя, Время, Тревоги, Статус

Бот при нажатии «🏆 Топ игроков» читает этот файл, сортирует записи по времени (от большего к меньшему) и выводит в чат. При нажатии «🏅 Мои ачивки» бот ищет все записи с вашим именем и проверяет условия:

Спринтер: время хотя бы одной сессии больше 60 секунд.

Марафонец: суммарное время во всех сессиях больше 180 секунд.

Документация сессий (Stateless)
Состояние пользователя хранится не в оперативной памяти, а в файлах sessions/{user_id}.json. Пример сессии:
```
{
  "state": "MENU",
  "name": "Артем",
  "subscribed": true,
  "screen_message_id": 123,
  "screen_chat_id": 456789
}
```
Это позволяет боту перезапускаться без потери данных о подписках и именах пользователей.

Логирование
Все важные действия бота записываются в файл bot_flight.log с указанием времени. Это помогает отслеживать ошибки и проверять работу хендлеров при защите лабораторной.
