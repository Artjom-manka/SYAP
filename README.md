# Inertial Tanks

2D-игра на Pygame с инерционным управлением танком, лабиринтом из JSON,
логированием событий и таблицей рекордов в CSV.

Игрок управляет танком, который движется по инерции: нажатие клавиши
добавляет ускорение, а не мгновенно меняет позицию. Задача — исследовать
лабиринт, не застревая в стенах. Все ключевые события пишутся в лог,
результаты сессий сохраняются в таблицу рекордов.

---

## Стек технологий

- **Python 3.9+**
- **Pygame 2.6.1** — окно, ввод, отрисовка, коллизии

Механики игры
1. Инерционное движение
Танк не двигается «по клеткам», а имеет скорость (vx, vy) и угол angle.

Нажатие W/S добавляет ускорение по направлению танка.

Каждый кадр скорость умножается на friction = 0.98.

Максимальная скорость ограничена max_speed = 3.

Поворот — rotation_speed = 3 градуса за кадр при удержании A/D.

Инерция проявляется так: после отпускания клавиши танк продолжает скользить
и постепенно останавливается. Резко развернуться на месте нельзя — нужно
сначала погасить скорость.

2. Коллизии
Стены уровня хранятся как список pygame.Rect (по одному на символ #).
Коллизия проверяется по окружности:

```python
def check_circle(self, cx, cy, rect):
    closest_x = max(rect.left, min(cx, rect.right))
    closest_y = max(rect.top, min(cy, rect.bottom))
    dx = cx - closest_x
    dy = cy - closest_y
    return dx * dx + dy * dy <= self.radius * self.radius
```
Движение разбито на две попытки (try_move по X, затем по Y) — так танк
«скользит» вдоль стены, а не застревает намертво. При столкновении
соответствующая компонента скорости обнуляется.

3. Границы окна
Если танк выходит за пределы 800×640, его позиция откатывается,
а скорость по этой оси обнуляется.

Файлы данных
levelPlayer.json — конфигурация уровня
Внешний JSON-файл со структурой лабиринта. Загружается при старте игры
через file_manager.load_level().
```json
{
  "name": "Arena 1",
  "tile_size": 40,
  "grid": [
    "################",
    "#..............#",
    "#..###....###..#",
    "#..#........#..#",
    "#......S.......#",
    "#..#........#..#",
    "#..###....###..#",
    "#..............#",
    "#..............#",
    "#..............#",
    "#....#...#.....#",
    "#........#.....#",
    "#....#.........#",
    "#..............#",
    "################"
  ],
  "player": {
    "x": 1,
    "y": 1,
    "angle": 0
  },
  "spawns": [ [ 1, 1 ] ]
}
```
Поля:

Поле	Тип	Назначение
name	str	Имя уровня (для логов)
tile_size	int	Размер тайла в пикселях (40)
grid	list[str]	Матрица уровня: # — стена, S — спавн, . — пол
player	dict	Начальные координаты и угол (справочно)
spawns	list	Список координат спавна (справочно)
Все строки grid должны быть одинаковой длины, иначе уровень не пройдёт
валидацию и будет загружен DEFAULT_LEVEL.

levelDefault.py — уровень по умолчанию
```python
DEFAULT_LEVEL = {
    "name": "Default",
    "tile_size": 40,
    "grid": [
        "####################",
        "#S.................#",
        "#..................#",
        "#..................#",
        "####################",
    ],
    "player": {"angle": 0},
}
```
Используется, если levelPlayer.json:

отсутствует (FileNotFoundError);

повреждён (json.JSONDecodeError);

не прошёл валидацию (нет поля grid, разная длина строк, нет S
или больше одной S).

game_flight.log — лог событий
Текстовый файл, пишется модулем logging. Формат строки:

text
2026-10-27 21:01:31 | INFO | Уровень загружен из levelPlayer.json
2026-10-27 21:01:31 | INFO | Игра запущена
2026-10-27 21:01:32 | INFO | Нажата кнопка START
2026-10-27 21:02:14 | INFO | Результат сохранён: сессия 1, Прервано
2026-10-27 21:02:14 | INFO | Выход в меню по ESC
Формат задаётся в file_manager.py:

```python
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format="%(asctime)s | %(levelname)s | %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
)
```
Логируются:

загрузка уровня / fallback на DEFAULT_LEVEL;

запуск и завершение игры;

нажатия кнопок START и EXIT;

сохранение результата сессии;

выход в меню по Esc.

agent_logs.csv — таблица рекордов
Табличный файл, дописывается через csv.writer (режим "a").
Колонки: Сессия, Время, Тревоги, Статус.

Пример:

text
Сессия;Время;Тревоги;Статус
1;2.2;0;Прервано
2;1.1;0;Прервано
3;1.4;0;Выход
Особенности:

кодировка cp1251 — чтобы Excel открывал русские заголовки без
«кракозябр» (родная кодировка русской Windows);

при первом запуске (файл отсутствует или пуст) сначала пишется
строка заголовков;

Порядок вызовов в main.py:

```python

grid = config["grid"]
walls = Labirint.build_walls(grid)
start_x, start_y = Labirint.get_start_position(grid)
player = Tank.Tank(start_x, start_y, 0.07, 1.5)
Внутри file_manager.load_level():
```
load_config() — пытается открыть levelPlayer.json.

FileNotFoundError → печать в консоль + запись в лог + return {}.

json.JSONDecodeError → печать + запись в лог + return {}.

Успех → log_event("Уровень загружен...") + return data.

validate_level(config) — проверки:

конфиг не пустой;

есть поле grid и оно не пустое;

все строки одинаковой длины;

ровно один символ S.

Если валидация провалилась — возвращается DEFAULT_LEVEL.

Иначе — валидный конфиг.

Такой подход покрывает все требования методички: обработка
FileNotFoundError, JSONDecodeError, валидация, fallback.
